# 输出模板定义

> 小红书「大家补充了」Skill — 输出渲染层参考
> 版本：v1.2 | 日期：2026-05-30

---

## 一、标准版模板（默认）

### 1.1 完整结构

```
大家补充了 N 点

我看了这篇笔记的评论区（{total_comments} 条评论）{image_context}，
比较有价值的补充主要集中在下面几点：

1.【有人补了一句】（如有 supplement 类型）
{summary}。主要是说：{elaboration}。
（约 X 条相关评论）

2.【有薯提醒】（如有 warning 类型）
有薯友提醒：{summary}。
这不是说原笔记有问题，而是有薯友遇到了需要注意的情况：{elaboration}。
（约 X 条相关评论）

3.【也有人不一样】（如有 different_exp 类型）
评论区和正文/图片体验不一样的也有：{summary}。
{elaboration}。
（约 X 条相关评论）

4.【关于图的讨论】（如有 visual_dispute 类型 + 有图片理解结果）
有不少薯友提到了图片/视频方面的事：{summary}。
{elaboration，引用图片观察但不做判定}。
（约 X 条相关评论）

5.【大家基本认可】（如有 consensus 类型）
这方面评论区整体比较一致：{summary}。
{elaboration}。
（约 X 条相关评论）

6.【最近有人说】（如有 recent_change 类型 + 近7天评论）
最近的评论里有新信息：{summary}。
⚠️ 时效性强，建议再看原评论确认。
（约 X 条近期评论）

---
以上是评论区比较集中的几点补充，
建议大家结合自身情况参考，具体以实际情况为准哦～
```

### 1.2 变量说明

| 变量 | 来源 | 示例 |
|------|------|------|
| `N` | 非空聚类类型的计数 | 3 |
| `total_comments` | API 返回的评论总数 | 5481 |
| `image_context` | 有图片时显示 | "（含 X 张配图）"；无图时不显示 |
| `summary` | 该聚类下评论的核心观点概括 | "很多人提到价格比笔记写的贵" |
| `elaboration` | 具体展开（不含原评论文本，除非 need_evidence=true）| "主要集中在交通费和门票两个方面" |
| `X` | 该聚类的代表评论数估算 | 约 120 条 |

### 1.3 动态区块规则

- **每个聚类类型对应一个编号区块**
- **只有该类型存在有效聚类结果时才渲染对应区块**
- **区块编号始终从 1 开始连续编号**（即使跳过了某些类型）
- **最少 1 个区块，最多 6 个区块**

### 1.4 排序优先级

默认排序（按重要性递减）：
1. `warning` （避坑提醒最重要）
2. `supplement` （实质性补充）
3. `different_exp` （不同体验）
4. `visual_dispute` （关于图的讨论）
5. `consensus` （共识）
6. `recent_change` （最新动态）

**focus 参数可调整排序**：如用户说"只看避坑"则 warning 排最前且其他弱化。

## 二、简短版模板（可选，P1.5 实现）

```
这篇的评论区主要有这些声音：

⚠️ 有薯友提醒：{一句话总结}
➕ 也有人补充：{一句话总结}
↔️ 不同体验：{一句话总结}
{如有图的相关讨论 → 🖼️ 关于图：{一句话总结}}
{如有最新信息 → 🕐 最近更新：{一句话总结}}

建议大家看看原评论了解更多详情～
```

## 三、详细版模板（可选，P1.5 实现）

在标准版基础上增加：
- 每个区块附带 2-3 条代表性原评论（匿名化处理）
- 增加数据统计段落（地域分布/时间分布/热度趋势）
- 图片观察段落单独展开
