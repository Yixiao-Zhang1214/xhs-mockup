📋 如何获取 Cookie

  1. 在浏览器打开 xiaohongshu.com 并登录
  2. 按 F12 打开开发者工具
  3. 点击 Application → Cookies → xiaohongshu.com
  4. 找到 web_session 或 a1 项，复制 Value 值
  5. 粘贴到下方输入框

支持：完整URL / xhslink.com 短链接
